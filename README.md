## Cómo trabajo

- **Los datos primero:** antes de modelar o graficar reviso nulos, duplicados y fugas de datos, y dejo escritos los límites de la información.
- **Cifras verificadas:** lo que se afirma en una presentación sale de los datos y se comprueba con código.
- **Con IA, y diciéndolo:** uso asistentes de IA para programar más rápido y revisar; cada proyecto aclara qué herramientas intervinieron.
